# ⚔️ Il Dungeon

Il gioco a carte delle discese: una mappa a nodi, un bivio alla volta, una
domanda per ogni sfida. Il codice sta in `src/giochi/dungeon/`.

- [presentazione.md](presentazione.md) — per chi arriva da fuori: come è fatto, cosa allena, note per i genitori
- [regole.md](regole.md) — il bottino, la difficoltà per riga, il bestiario, perché non c'è la pausa

Vedi anche: `src/giochi/dungeon/COMBATTIMENTO.md` (armi, armature e mostri con
la vita), [../sotterraneo/README.md](../sotterraneo/README.md) (l'altro gioco a
discese, un posto invece che un diagramma),
[../core/grafica.md](../core/grafica.md) (lo scheletro di `corpo.js`),
[../apprendimento/presentazione.md](../apprendimento/presentazione.md) (le
domande di tutte le materie).
