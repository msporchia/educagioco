# ⏭️ Prima e dopo

Rimettere in fila una storia, per i quattro-sei anni (`src/giochi/prima-dopo/`).

- [presentazione.md](presentazione.md) — il gioco, i sei modi di chiedere, le storie e le tappe, le note per i genitori
- [disegni.md](disegni.md) — la regola delle icone (vale per tutti i giochi), perché le storie si disegnano, le regole imparate disegnando, come si scrive una storia
- [da-fare.md](da-fare.md) — le storie ancora a emoji, il cassetto dei concetti da promuovere a `src/grafica/`

Vedi anche: le regole per scrivere una storia in testa a
`src/giochi/prima-dopo/dati/storie.js`; [../core/convenzione-giochi.md](../core/convenzione-giochi.md).
