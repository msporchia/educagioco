# 🏃 La corsa dei numeri

Tre corsie, tre cancelli con un conto sopra, una truppa che è un numero
scritto in terra. Ancora fra i giochi in prova. Il codice sta in
`src/giochi/corsa/`.

- [presentazione.md](presentazione.md) — per chi arriva da fuori: come si gioca, cosa allena, note per i genitori
- [regole.md](regole.md) — cancelli, truppa a gradi, mostri, cancello d'oro, ritmo, pausa, stelle e corsa infinita, coi perché
- [scena.md](scena.md) — perché la strada è disegnata così: quanta vista prende, i cancelli, la truppa

Vedi anche: [../core/primati.md](../core/primati.md) (il record della corsa
infinita), [../core/interfaccia.md](../core/interfaccia.md) (la pausa),
[../apprendimento/presentazione.md](../apprendimento/presentazione.md) (le
domande del cancello d'oro).
