# Apprendimento

Come si impara nei giochi: il ripasso, le domande di quiz, l'età, cosa si dà
per scontato, e quanto vale una moneta.

- [presentazione.md](presentazione.md) — le domande spiegate a chi arriva da fuori
- [srs.md](srs.md) — il motore di ripasso (`src/store/srs.js`) e la marea; prima di toccarlo
- [quiz-moduli.md](quiz-moduli.md) — il contratto di un modulo, come aggiungerlo, provarlo e usarlo in un gioco
- [quiz-livelli.md](quiz-livelli.md) — la difficoltà 0–100, ammissione e mira, la banda, si pesca una classe
- [quiz-ripasso.md](quiz-ripasso.md) — la banda 1.5/0.5, le chiavi dei concetti e i loro prefissi
- [la-domanda.md](la-domanda.md) — dopo la risposta: tempo per leggere, fretta, perché e come si fa, il muro
- [saperi.md](saperi.md) — i pezzi di scuola che si spengono, chi li dichiara, il criterio
- [saperi-per-fascia.md](saperi-per-fascia.md) — la ricerca con le fonti dietro ogni fascia
- [eta-e-portata.md](eta-e-portata.md) — le partenze per età, i flag del manifesto, la portata delle tappe
- [calibrazione.md](calibrazione.md) — una moneta = dieci secondi: prezzi, premi, curve; prima di scrivere un prezzo
- [livelli-delle-domande.md](livelli-delle-domande.md) — tutte le classi per livello (generato: `npm run quiz:livelli`)
- [chi-vede-cosa.md](chi-vede-cosa.md) — cosa arriva a ogni età (generato: `npm run quiz:eta`)
- [da-fare.md](da-fare.md) — le voci aperte

Vedi anche: [../genitori/](../genitori/README.md) per la manopola dell'età
([manopola.md](../genitori/manopola.md)), i ritocchi e «Come va»; il perché di ogni costante in testa ai file di
`src/quiz/nucleo/`.
